# 🏨 Hotel Management System

A full-stack hotel management application designed to streamline room bookings, reservations, customer management, and administrative operations through a responsive web interface and a secure REST API backend.

## 📌 Overview

The **Hotel Management System** is a full-stack web application developed to simplify hotel operations and improve the management of rooms, reservations, and customer information.

The project consists of two separate applications: a **Frontend Web Application** and a **Backend API**. The frontend provides a responsive and user-friendly interface, while the backend handles business logic, database operations, authentication, and authorization.

The system uses JWT-based authentication, role-based access control, and REST APIs to support secure and efficient hotel management workflows.

## 📂 Project Repositories

The project is organized into two separate repositories for frontend development and backend services.

### 🌐 1. Frontend Application

The frontend provides a responsive interface for hotel management operations, including room bookings, reservations, customer management, and administrative workflows.

🔗 **GitHub Repository:** [hotel_management_system](https://github.com/DonShanilka/hotel_management_system)

### ⚙️ 2. Backend API

The backend provides REST APIs and server-side services for reservation processing, customer management, database operations, authentication, and authorization.

🔗 **GitHub Repository:** [hotelmanager_expressjs_backend](https://github.com/DonShanilka/hotelmanager_expressjs_backend)

## 🚀 Getting Started

Clone the frontend and backend repositories separately.

### Frontend Application

```bash
git clone https://github.com/DonShanilka/hotel_management_system.git
cd hotel_management_system
```

Install dependencies and start the frontend according to the project's setup instructions.

### Backend API

```bash
git clone https://github.com/DonShanilka/hotelmanager_expressjs_backend.git
cd hotelmanager_expressjs_backend
```

Install dependencies, configure environment variables, set up the MySQL database, and run the backend according to its setup instructions.

### Configuration

Depending on the implementation, the applications may require:

- MySQL database connection settings
- Prisma database configuration and migrations
- JWT secret configuration
- Backend API URL for frontend communication

Use environment variables for sensitive configuration values and follow the setup instructions in each repository.
